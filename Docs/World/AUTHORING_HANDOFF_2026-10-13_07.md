## Reproduction

Use the configured Python runtime with `Tools/World/check_chronology.py`, `Tools/World/check_people.py --negative-controls`, `Tools/World/check_city_region_accounts.py`, and `Tools/World/build_settlement_network.py --check`. Omit the last tool's `--check` to regenerate its SVG/report. `Tools/World/build_settlements.py hesh --check` checks the modified Hesh record.

Compile with `Tools/World/build_reader.cjs` and bundled `marked`; inspect with `Tools/World/inspect_reader.cjs <Edge path>` and `Tools/World/inspect_world_plate.cjs <Edge path> settlements` using bundled Playwright. Run `Tools/Preflight.ps1` for the repository checks. No new package installation or engine upgrade is required.
